## Project windows, artwork, and tools

Project windows use a shared scrollable layout on desktop and mobile, with full
descriptions, technology lists, source/demo links, maximize/restore, and shareable
`#project=<id>` URLs. Each selected experience has at least three factual points.
The requested footer tagline has been removed.

Project SVG banners are generated from the shared JSON by `build-artwork.mjs`
automatically before development and production builds. See README for the schema
and refresh command when editing projects while the dev server is already running.

The Tools navigation goes to a separate `/tools` page with Link Lab, Checksum
Studio, Photo Privacy Studio, File Identity Inspector, and Unicode Lens.
It uses a second Vite entry rather than a client-side catch-all router.
Operations run in the browser except
explicit URL shortening, which uses `/api/shorten` and is.gd. The server validates
URLs, applies an in-memory rate limit/cache, and enforces an upstream timeout.
Tool checks use mocked upstream responses; they do not create live short links.
The generic password, JWT, timestamp, and text tools were replaced after research
into photo metadata privacy, file-signature validation, and Unicode security.
Source links and the limitations of each replacement are documented in README.

Window controls now use traffic-light hover/focus glyphs, animated close and
dock transitions, title-bar double-click, keyboard-accessible dock restoration,
and reduced-motion handling. Maximized windows retain that state after minimizing.
