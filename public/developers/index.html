Developer portal

This portfolio provides human-readable pages and machine-readable representations of the same profile. Start with llms.txt, OpenAPI, or the sitemap.

Read-only API

  • GET /api/v1/profile — profile and education
  • GET /api/v1/experience — selected experience
  • GET /api/v1/skills — skills grouped by area
  • GET /api/v1/projects — selected public projects

JSON responses include apiVersion and data. Read endpoints are public and rate-limited to 60 requests per IP per minute per function instance. Responses advertise RateLimit headers. Invalid requests use RFC 9457 problem details. See OpenAPI for supported filters.

Markdown pages

Canonical pages support Accept: text/markdown, a .md suffix, and ?mode=agent. Known AI crawler user agents also receive markdown. Browser requests continue to receive HTML. Responses vary on Accept and User-Agent. Unknown paths return HTTP 404.

AI assistant

POST /api/v1/chat is an optional origin-restricted AI endpoint, limited to 10 requests per IP per minute per function instance. It requires the deployment owner to set OPENAI_API_KEY on the server. See authentication guidance for request details. Never place API keys in client code.

URL-shortening tool

POST /api/shorten accepts a JSON url field and creates a public link through is.gd. It is unauthenticated and limited to 10 requests per IP per minute per function instance. Success returns a shorturl field; failures return an error field with a non-2xx status. This unversioned utility is separate from the read-only v1 API and its problem-detail contract.

Source accuracy

Projects link to their public repositories. Learning interests are separated from skills, education is marked in progress, and team prototypes are identified as such. Use kushh4@proton.me for questions that the published profile does not answer.
