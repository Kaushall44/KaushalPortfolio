Privacy

Last reviewed: 2026-10-06. This page describes the features included in this portfolio.

Camera controls

Hand-gesture and head-tracking controls are optional and require browser permission. Camera frames are processed on your device for navigation; this application does not upload or store the camera feed. Disable camera controls when you are finished. The browser may download MediaPipe model assets from external hosts.

Browser storage

The site uses browser storage for interface preferences, including your theme and whether you have seen the gesture introduction. You can clear this data through your browser settings. Some interactive features use browser messaging to coordinate portfolio tabs.

Browser tools

Checksums, photo re-export, file-signature inspection, Unicode inspection, and URL cleaning run locally. Selected files and images are not uploaded. Choosing Shorten sends the URL through /api/shorten to is.gd to create a public link. Avoid private or signed URLs. The server temporarily caches shortening results and IP-based rate-limit counters in memory.

Optional AI chat

If the deployment has AI chat configured, messages you submit to the terminal AI assistant are sent to a server endpoint and then to OpenAI to generate a response. Do not include sensitive personal information. The server uses a temporary in-memory IP-based counter for rate limiting. Ordinary terminal commands run locally.

Analytics and hosting

No third-party analytics is initialized by this application. The hosting provider may process ordinary request logs for operation and security. External resources, such as fonts and model downloads, and sites opened through project links have their own privacy policies.
